# @poe2htc/engine

Pure TypeScript crafting engine (Phase 1). **No I/O, no DOM** — takes a data snapshot + item state,
returns outcome probabilities. Ports the proven Java design (`src/main/java/core/Crafting/**`),
differential-tested against it on identical data.

## Layout

- `types.ts` — data model, mirrors `data/patches/<patch>/{mods,base_items}.json`. `CURRENCY_FLOOR`
  (base 0 / greater 35 / perfect 50) from `ExaltAndRegalProbability.java`.
- `pool.ts` — weight math + family-exclusion + ilvl gates (`modTierWeight`, `poolTotalWeight`,
  `familyAvailable`).
- `item.ts` — immutable `ItemState` (max 3 prefixes + 3 suffixes), `whiteItem`.
- `probability.ts` — `addAffixProbability` (faithful port of `NormalCompute`, the shared
  transmute/aug/regal/exalt weight-pool math) and `transmuteProbability`.
- `loadPatch.ts` — the only file that touches the filesystem; `indexPatch()` is pure (browser/worker
  safe).

## Tests

```bash
npm run test:engine        # unit + differential
npm run type-check:engine
```

- `probability.test.ts` — hand-computed probabilities on a tiny synthetic pool (per CLAUDE.md), plus
  real-0.5 invariants (transmute distribution sums to 1).
- `transmute.differential.test.ts` — asserts TS === Java to 12 dp, using a fixture generated by the
  Java engine (`npm run fixtures:java` → `core.data.TransmuteProbe`). Regenerate the fixture when the
  transmute math or the 0.5 data changes.

## Status / next

Implemented: item state, mod pools, family exclusions, ilvl gates, currency-tier floors, omen
side-constraint, **transmute** (differential-green). Next currencies reuse `addAffixProbability`:
